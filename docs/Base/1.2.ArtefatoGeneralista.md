# 1.2. Módulo Artefato Generalista

## Introdução

Os **Artefatos Generalistas** constituem o módulo de projeto não orientado a abordagens específicas, possuindo aplicabilidade em diversos contextos independentemente da metodologia adotada, como Scrum ou Kanban. No contexto deste projeto, eles atuam como pilares para o **Desenho e a Arquitetura de Software**, traduzindo requisitos do mundo real para o mundo computacional através de diferentes níveis de abstração. O objetivo principal é produzir um projeto de solução estratégico e lógico que defina não apenas **o quê** é a solução, mas também **como** ela deve ser implementada nas especificações de hardware e software definidas.

## Metodologia

A metodologia para a concepção da base do projeto envolveu a seleção de ferramentas visuais e analíticas para detalhar o escopo, identificar causas de problemas e alinhar o conhecimento técnico e de domínio entre a equipe. A elaboração foi colaborativa, utilizando os seguintes artefatos conforme a estratégia de projeto definida:

- **Rich Picture**: Utilizado para retratar o ponto de vista dos interessados e fluxos de informação, permitindo anotar funcionalidades e garantir o rastro para as fontes de informação.
- **5W2H**: Aplicado para estruturar o planejamento em baixo nível de abstração, definindo aspectos como escopo, responsáveis, cronograma e custos.
- **Diagrama de Causa e Efeito (Ishikawa)**: Empregado na análise de problemas e seus impactos, mapeando causas raiz através da estrutura de 6M (Método, Máquina, Material, Mão de Obra, Medida e Meio Ambiente).
- **Estimativas**: Realizadas para lidar com as incertezas de prazo, custo e esforço, baseando-se em requisitos e restrições para a elaboração do cronograma do projeto.
- **Glossário**: Construído para unificar a linguagem do domínio, definindo termos de forma clara para facilitar a comunicação e o entendimento comum de todos os envolvidos.

## Princpais Artefatos utilizados

### Rich Picture

Rich Picture final, criado a partir do consenso do grupo sobre as melhores ideias e representações.

### 5W2H

5W2H em baixo nível de abstração, definindo escopo, cronograma e custos.

### Diagrama de Causa e Efeito (Ishikawa)

Diagrama de Causa e Efeito seguindo o padrão 6Ms para percepção do problema e suas causas.

### Estimativas

Tabela de estimativas utilizando o método de "Avaliação de Especialistas", as estimativas feitas de maneira anônima e separada, para evitar influência entre membros, onde após isso, foi feita uma discussão para chegar a valores finais baseado nas estimativas.

### Glossário

Tabela de Glossário para definição de termos de forma clara para o entendimento de todos os envolvidos.
